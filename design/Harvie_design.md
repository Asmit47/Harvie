# Harvie Design System

## Purpose

This document defines the visual language of Harvie.

It should remain stable as the product evolves.
Individual pages should follow these rules rather than redefining them.

---

# Design Philosophy

Harvie should feel

- Calm
- Intelligent
- Premium
- Futuristic
- Spatial
- Minimal

Avoid looking like a generic SaaS dashboard.

Design for focus instead of decoration.

# Glassmorphism

Glass should only be used for

- Floating cards
- Dialogs
- Command Bar
- Tooltips
- Context menus

Avoid making every component glass.

Keep opacity low.

Use subtle blur.

Thin borders only.

# Guardrails

DO

- Keep UI minimal
- Prioritise readability
- Use whitespace
- Keep visual hierarchy

DON'T

- Build a generic SaaS dashboard
- Use neon everywhere
- Overuse gradients
- Overuse glass
- Mix styles
